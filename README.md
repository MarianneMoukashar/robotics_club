# 👾aubm_robotics_club👾
This repository is for the AUB Mediterraneo Robotics club!

## Our robot!
This is **`Archie`**, the first fully functioning robot made at AUB Mediterraneo! We named him after the greek word **`ἀρχή`**(archē), meaning start/beginning.
